# ローカルの議案データ

この公開リポジトリには、公式資料の取得コピー、原文入りJSON、AI候補、確認記録を含めていません。これらは現在の開発環境の `data/` に残しており、削除していません。

姫路市の[著作権・リンク・免責事項](https://www.city.himeji.lg.jp/site_policy/0000000009.html)を確認し、個々の資料の再配布条件が未確認の段階では一括公開しない方針です。すべての資料が同じ権利状態にあると判断したものではありません。

**クローンだけではアプリの起動・データテスト・ビルドはできません。** `app/` と `lib/data/` は検証済みのローカルJSONを読み込みます。元の開発環境から、利用権限と確認履歴を保持してデータを戻す必要があります。空のデータや架空の議案で検証を通すことはしません。

取り込み・検証用のプログラムは `scripts/`、型は `lib/data/`、取得元の案内は `app/sources/page.tsx` にあります。再取得だけでは人の確認記録は復元できません。GitHubとは別に、ローカルの `data/` と `reports/` をバックアップしてください。秘密のAPIキーをバックアップやリポジトリに混ぜないでください。

資料の再配布条件を確認して掲載範囲を見直すまで、`git add -f data/` で強制登録しないでください。
