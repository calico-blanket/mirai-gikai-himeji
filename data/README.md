# ローカルの議案データ

**2026年9月26日に方針を見直しました。** 姫路市の[著作権・リンク・免責事項](https://www.city.himeji.lg.jp/site_policy/0000000009.html)は「二次利用（複製・転載・転用・販売など）を固く禁じる」と表示していますが、この表示自体が著作権法の権利制限規定（事実の利用・引用等）を上書きする効力は持ちません。これを踏まえ、`data/` を次の2種類に分けて扱います。

- **`data/sources/`（Git管理外・ローカルのみ）**：姫路市公式サイトから取得した原資料そのもの（PDF・HTML・会議録APIの原本）。これは著作物の丸ごとの複製にあたるため、再配布条件が未確認の段階では公開リポジトリに含めません。
- **それ以外（`data/himeji-2025-4.json`、`data/candidates/*`、`data/editorial/*`。Git管理下）**：議案番号・議決結果・賛否記号などの事実データ、AIによる独自の説明・分類、会議録の該当段落の抜粋（出典明記のうえでの引用）です。事実データ自体は著作権の対象外、AI生成物は独自表現のため、公開リポジトリに含めています。

**`data/sources/` はクローンだけでは揃いません。** アプリ自体は `data/candidates/` 等のJSONだけで起動・データテスト・ビルドができますが、`scripts/` 配下の再取得・再抽出スクリプト（`fetch_himeji_minutes.py` 等）を実行するには、元の開発環境から `data/sources/` を個別に用意する必要があります。

取り込み・検証用のプログラムは `scripts/`、型は `lib/data/`、取得元の案内は `app/sources/page.tsx` にあります。GitHubとは別に、ローカルの `data/sources/` をバックアップしてください。秘密のAPIキーをバックアップやリポジトリに混ぜないでください。
